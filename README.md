# RpPluginByEfes

A Roleplay (RP) plugin for SCP: Secret Laboratory (EXILED). It provides 3D text for RP messages and a custom HUD.

**DEPENDENCY:** You MUST install `HintServiceMeow` (HSM) for this plugin to work. Place HSM in your `EXILED/Plugins/dependencies` folder.

## Features
- `.do`, `.me`, `.ooc` commands for roleplaying.
- `.dice` (or `.zarat` in TR mode) command for rolling a 1-6 dice.
- HUD in the bottom left showing TPS and Player Count.
- Configurable colors, message durations, and language modes (English / Turkish).

## Installation
1. Install EXILED.
2. Install HintServiceMeow (HSM) into `dependencies`.
3. Put `RpPluginByEfes.dll` into `EXILED/Plugins`.
4. Restart your server.
