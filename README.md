# RpPluginByEfes

Roleplay HUD plugin for SCP: Secret Laboratory (EXILED).

**Requirement:** You must install `HintServiceMeow` into your `EXILED/Plugins/dependencies` folder.

## Features
- Displays Server TPS, Player Count, and Roles on the HUD.
- Adds `.do`, `.me`, and `.ooc` commands to the screen.
- Adds `.dice` (or `.zarat`) command for rolling a dice.
- HUD is visible to spectators.
- Configurable coordinates, sizes, colors, and languages (English / Turkish).

## Installation
1. Install EXILED on your server.
2. Put `HintServiceMeow.dll` into `EXILED/Plugins/dependencies/`.
3. Put `RpPluginByEfes.dll` into `EXILED/Plugins/`.
4. Restart your server.
